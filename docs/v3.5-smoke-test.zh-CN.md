# V3.5 冒烟测试报告（第一次真正跑模型）

> 日期：2026-10-23
> 目的：验证“照片 → 预处理 → ONNX 推理 → 输出标签”这条技术链路能不能跑通。
> **不是准确率评测，不代表最终标签效果。**
> 全程只读 E 盘，不接 API，不修改任何照片。HEIC 暂不处理（按你的要求先忽略）。

---

## 1. 测试条件

| 项目 | 内容 |
| --- | --- |
| 模型 | MobileNetV2（ONNX Model Zoo，Apache-2.0） |
| 模型大小 | 13.59 MB |
| 运行库 | onnxruntime 1.31.0，CPU |
| 图像库 | Pillow 12.3.0 |
| 数值库 | numpy 2.5.4（本次新装） |
| 样本 | 20 张 JPG（NEF+JPG 同组优先 JPG）+ 3 张 NEF 内嵌预览 |
| 来源 | 建筑场景（10 组）与湖畔日出（10 组） |
| HEIC | **未测试**（按你的要求先忽略） |

---

## 2. 只读安全验证

- 测试前后对 20 张 JPG + 3 张 NEF 做 **SHA-256 + 大小 + 修改时间** 对比；
- **23/23 全部一致，E 盘没有任何文件被修改**；
- 模型、缓存、结果全部在 C 盘 `.dsh_work`，没有写入 E 盘。

---

## 3. 结果

### 3.1 能不能跑通

| 项目 | 结果 |
| --- | --- |
| 模型加载 | 成功，72.9ms |
| 输入形状 | `[1, 3, 224, 224]` |
| 模型输出 | 1000 类分数，正常 |
| JPG 推理 | 20/20 成功 |
| NEF 内嵌预览 | 3/3 成功（不需要 RAW 解码） |
| E 盘文件改动 | 0 |
| 崩溃 / 报错 | 0 |

### 3.2 耗时

| 项目 | 结果 |
| --- | --- |
| 纯推理（不含读图/预处理） | 约 **1.8–2.0ms/张** |
| JPG 全流程（读图+预处理+推理） | 最低 170ms，平均 **187ms**，最高 216ms |
| NEF 全流程（内嵌预览+预处理+推理） | 约 **128–130ms/张** |
| 20 张总耗时 | 约 3.7 秒（不含模型加载） |

结论：**推理不是瓶颈**，时间主要花在 JPEG 解码、缩放和 numpy 预处理上。

### 3.3 模型输出示例（ImageNet 类别，不是最终标签）

| 照片 | Top-1 类别 | 置信度 |
| --- | --- | --- |
| 建筑场景 样本 A1 | boathouse（船屋） | 0.35 |
| 建筑场景 样本 A2 | handrail（栏杆） | 0.24 |
| 建筑场景 样本 A3 | boathouse | 0.89 |
| 湖畔日出 样本 B1 | lakeside, lakeshore（湖岸） | 0.28 |
| 湖畔日出 样本 B2 | lakeside, lakeshore | 0.64 |

这些类别说明：**模型确实在看画面内容**，湖畔日出被识别为“湖岸”，建筑场景被识别为“船屋/栏杆”，不是随机结果。

但 ImageNet 的 1000 类不是我们要的中文标签（建筑/天空/水面/日落……），所以：

- 这次只证明“技术链路能跑”；
- **不能拿这些类别直接当 V3.5 标签**；
- 真正的中文标签需要 Places365 场景分类或 CLIP 零样本，并做映射/校准。

---

## 4. 这次证明了什么

- ONNX Runtime 在你的机器上可用；
- NEF 内嵌预览可以直接转 RGB 送入模型，不需要 RAW 解码；
- JPG 解码、缩放、归一化、推理这条链路完整可用；
- 单张推理约 2ms，CPU 完全够用；
- E 盘只读、无改动；
- 模型/缓存可以完全放在 C 盘，不占 E 盘。

## 5. 这次没有证明什么

- **准确率**：没有人工答案，不能算 precision/recall/F1；
- **中文标签效果**：ImageNet 类别不是我们的标签；
- **HEIC**：未测试，手机照片暂时不算；
- **全库性能**：只测了 20 张，没跑 1,375 / 7,204 张；
- **显存/GPU**：本次只用 CPU，GPU 未测。

---

## 6. 估算（含预处理，不含未来模型差异）

按 JPG 全流程 187ms/张粗算：

| 场景 | 不去重 | NEF+JPG 配对去重后 |
| --- | --- | --- |
| 1,375 张 | 约 4.3 分钟 | 约 2–2.5 分钟 |
| 7,204 张（户外活动样本） | 约 22 分钟 | 约 11–12 分钟 |

配对去重仍然重要：同一张照片的 NEF+JPG 只跑一次。

## 7. 结论与下一步

**技术路线通过冒烟测试**：

- 读取、预览、RGB 预处理、ONNX 推理都能跑；
- 没有 API、没有写 E 盘、没有改照片；
- 下一步不是继续堆模型，而是：
  1. 选一个**场景分类/CLIP** 模型（不是 ImageNet 1000 类），映射到 8 个中文标签；
  2. 做 150 张人工标注，测准确率；
  3. HEIC 等你说“再加”时补 `pillow-heif`；
  4. 全量测试最后做。
